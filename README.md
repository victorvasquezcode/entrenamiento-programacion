# 🚀 Entrenamiento de Programación

Mi camino para desarrollar habilidades avanzadas de programación, pensamiento algorítmico y resolución de problemas, con el objetivo de especializarme en **Ciencia de Datos e Ingeniería de Datos**.

## 🎯 Objetivo

Construir fundamentos sólidos de programación mediante práctica deliberada, resolución autónoma de problemas y aprendizaje progresivo.

## 🧠 Metodología

Cada sesión de entrenamiento incluye:

1. **Concepto técnico:** Comprender los fundamentos.
2. **Ejercicio práctico:** Aplicar lo aprendido.
3. **Desafío autónomo:** Resolver problemas sin depender de soluciones externas.

### Sistema de progresión

- 🔴 **Rojo:** Tema nuevo en aprendizaje.
- 🟡 **Amarillo:** Consolidación mediante ejercicios modificados y casos límite.
- 🟢 **Verde:** Tema dominado, sujeto a repasos periódicos.

## 📈 Filosofía de entrenamiento

> Primero entender el problema, después diseñar el algoritmo y finalmente escribir el código.

La prioridad no es completar ejercicios rápidamente, sino desarrollar razonamiento, autonomía y capacidad para construir soluciones correctas.
